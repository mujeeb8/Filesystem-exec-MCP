MCP Desktop Extension

Filesystem + Exec

Filesystem tools and optional command execution for Claude Desktop, jailed to directories you choose.

What this extension does

Filesystem + Exec is a local MCP server packaged as a .mcpb Desktop Extension. Once installed, it gives Claude two sets of capabilities:

  • Filesystem tools (always on): read, write, edit, search, move files, and walk directory trees — restricted to one or more directories you approve during setup.
  • Command execution tools (off by default): run_bash, run_shell, run_cmd, run_powershell, and run_command, which run real shell commands on your machine.
Command execution is high-privilege. When enabled, the connected AI agent can run any command your user account can run — installing packages, deleting files, changing settings — with no sandboxing beyond the working-directory restriction on the exec tools' cwd. Leave this off unless you have a specific reason to enable it, and only use it with clients you trust.

Installing

  1. Download the latest .mcpb file from the GitHub Releases page.
  2. In Claude Desktop, go to Settings → Extensions → Advanced settings → Install Extension…
  3. Select the downloaded .mcpb file.
  4. You'll be prompted to configure:
    SettingDescription
    Allowed DirectoriesOne or more folders the server may access. Nothing outside these is reachable.
    Enable command executionOff by default. Turn on only if you need the exec tools above.
  5. Restart Claude Desktop if prompted, then look for the tools icon in the chat input to confirm it's connected.

Available tools

Always available:

ToolPurpose
read_text_fileRead a text file, optionally just head/tail N lines
read_media_fileRead an image/binary file as base64
read_multiple_filesRead several files in one call
write_fileCreate or fully overwrite a file
edit_fileTargeted find/replace edits, with dry-run preview
create_directorymkdir -p semantics
list_directoryShallow directory listing
list_directory_with_sizesShallow listing with file sizes, sortable
directory_treeRecursive JSON tree of a directory
move_fileMove or rename a file or directory
search_filesRecursive case-insensitive filename search
get_file_infoStat a path — size, timestamps, permissions
list_allowed_directoriesShow the configured allowed root directories

Only present when command execution is enabled:

ToolPurpose
run_bashRun a command via /bin/bash -c (macOS/Linux)
run_shellRun a command via /bin/sh -c (POSIX)
run_cmdRun a command via Windows cmd.exe (Windows only)
run_powershellRun a command via PowerShell (powershell.exe on Windows, pwsh elsewhere)
run_commandGeneric — pick the shell explicitly: bash, sh, cmd, or powershell

Platform notes

Filesystem tools work identically on Windows, macOS, and Linux. For the exec tools:

  • run_cmd only works on Windows — on macOS/Linux it returns a clear error instead of failing silently.
  • run_powershell requires PowerShell Core (pwsh) to be separately installed on macOS/Linux; it is not bundled.
  • run_bash and run_shell work natively on macOS and Linux, and require WSL or Git Bash on Windows.

Troubleshooting

  • If tools don't appear after install, fully quit and reopen Claude Desktop (not just close the window).
  • A PathAccessError means a requested path fell outside your configured allowed directories — add the directory via the extension's settings rather than trying alternate paths.
  • Enable debug logging in Claude Desktop's settings to see extension-level logs if a tool call fails unexpectedly.
