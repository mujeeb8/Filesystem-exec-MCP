Privacy Policy

Filesystem + Exec — Privacy Policy

Last updated: 26 July 2026

Short version: this extension runs entirely on your own computer. It does not send any data anywhere, does not use the network, does not include analytics or telemetry, and does not have any account, server, or third party involved. Everything it does, it does locally, using the permissions you explicitly grant.

What this extension is

Filesystem + Exec is a Model Context Protocol (MCP) server that runs locally as a Claude Desktop Extension (.mcpb). It gives a connected AI agent tools to read, write, search, and organize files within directories you choose, and — only if you separately enable it — tools to run shell commands on your machine.

What data it accesses

Data typeFiles and directories inside the "Allowed Directories" you configure at install time. Nothing outside those directories is reachable by any tool in this extension.
Command outputIf you enable command execution, the standard output, standard error, and exit code of commands you (via the connected AI agent) choose to run.

What data it collects, stores, or transmits

None. Specifically:

  • This extension makes no network requests of any kind. There is no telemetry, analytics, crash reporting, or "phone home" behavior anywhere in the code.
  • It does not persist any data beyond the direct effect of the file operations you ask it to perform (e.g. a file you asked it to write stays written — the extension itself keeps no separate log or copy of your data).
  • It does not read, query, or have any access to your Claude conversation history or memory.
  • It has no user accounts, authentication, or associated backend service. There is nothing for us to store on our end because there is no "our end" — the server runs entirely inside your Claude Desktop installation, on your machine.

Third parties

None. No data is shared with any third party, because no data leaves your machine in the first place.

Command execution tool (optional)

If you explicitly enable command execution in the extension's settings, the connected AI agent gains the ability to run shell commands with your user account's privileges, scoped to a working directory inside your Allowed Directories. This is a powerful capability: a command you approve could read, modify, or transmit data on your system depending on what that specific command does. This extension does not restrict what a command can do once it runs — it only restricts the working directory the command starts in. This setting defaults to off, and we recommend leaving it off unless you have a specific, understood need for it.

Children's privacy

This extension is a developer tool for use with Claude Desktop and is not directed at children. It collects no personal data from anyone, of any age.

Changes to this policy

If this policy changes, the updated version will be published at this same location with a revised "Last updated" date, and noted in the project's release notes on GitHub.
